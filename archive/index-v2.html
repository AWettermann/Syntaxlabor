Syntaxdiagramm

Klicke direkt auf einen Baustein im Diagramm, um ihn zu bearbeiten, zu erweitern oder zu entfernen.

Grafischer Editor

Wähle einen Baustein im Diagramm aus.

Diagramm-Bausteine bearbeiten

Sequenz = hintereinander, Alternative = Verzweigung, Optional = 0 oder 1 Mal, Wiederholung = beliebig oft.

EBNF-Editor

Unterstützt werden , (Folge), | (Alternative), [ ] (optional), { } (Wiederholung), ( ) (Gruppierung), Literale und Regelnamen.

Wortprüfung

Prüft ein Wort gegen die aktuelle Diagrammstruktur. Nichtterminale werden über weitere EBNF-Regeln aufgelöst.

Bereit. Die Umwandlung erfolgt ausschließlich über die beiden Schaltflächen.
